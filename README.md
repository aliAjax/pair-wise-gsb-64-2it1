# 食品工厂HACCP控制计划与偏差处置平台

独立React前端工程，采用Fluent UI、Redux Toolkit、RTK Query、React Router、Vite和TypeScript。数据通过浏览器持久化，无需后端。

## 功能

- 生产批次、放行状态、监测点与隔离范围。
- HACCP流程图和控制矩阵编辑，记录关键限值、频率和纠偏措施。
- 偏差登记、原因与证据调查、返工/报废分支、复核退回和签字。
- 未关闭偏差阻止批次放行。
- 完整版本化审计和JSON追溯包导出。

## 生效依据（控制矩阵版本化）

控制矩阵、批次监测、偏差处置和放行结论共用同一份生效依据：

- 每次修改控制措施都会发布一个不可变的矩阵版本；批次投产时固定所依据的版本，旧批次不会按新限值放行。
- 矩阵更新后，所有未签字批次的放行结论立即按各自生效依据重算；已签字批次冻结结论，继续按签字依据展示。
- 超限补录先自动开偏差并冻结放行；偏差关闭后，须等同一控制点的后续合格读数确认，结论才转为符合放行。
- 补录读数携带幂等键：重复补传不重复记录、不重复开偏差；已被已关闭偏差覆盖的历史补录不再重新挑起偏差。
- 签字放行携带提交时的批次版本，两台终端同时提交时先到者生效，后到者保留填值并看到冲突，可按当前版本重新提交；另一标签页的提交通过storage事件实时同步。
- 本地写入失败时界面提示，未完成的监测点草稿独立保存，恢复后自动重放且不重复开偏差。
